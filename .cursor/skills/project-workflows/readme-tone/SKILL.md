# README Tone (존댓말)

이 프로젝트 README·사용 안내는 **딱딱하지 않은 존댓말**로 씁니다.  
공문체나 해체(`~한다`, `~둔다`)는 쓰지 않습니다.

## 종결 어미

| 용도 | 어미 | 예 |
|------|------|-----|
| 설명·소개 | ~합니다 / ~입니다 | 사용량을 표시합니다. |
| 단계 안내 | ~하세요 | `시작.bat`을 더블클릭하세요. |
| 앱·설치가 해 주는 일 | ~둡니다 | 바로가기도 만들어 둡니다. |
| 금지·주의 | ~마세요 | 토큰을 커밋하지 마세요. |
| 결과·상태 | ~됩니다 / ~습니다 | 이후에는 설치본이 실행됩니다. |
| 선택 가능 | ~할 수 있습니다 | 부팅 시 자동 실행을 켤 수 있습니다. |

## 피할 것

- 해체: `~한다`, `~둔다`, `~켠다`, `~읽는다`
- 과도한 공문체: `~하시기 바랍니다`, `~하여야 합니다`, `~하도록 한다`
- 커밋 메시지형 명사구 종결을 본문 문장에 남용 (`~반영`, `~추가` — 표·목록 제목은 예외)

## 섹션별 패턴

**도입 (1~2문장)**  
무엇인지 + 무엇을 하는지. `~합니다`로 마칩니다.

**사용 절차 (번호 목록)**  
각 단계는 `~하세요`. 부가 설명은 `~됩니다`, `~둡니다`.

**주의·경고**  
`~마세요`, `~않습니다`. 짧게.

**표의 「용도」 열**  
짧은 명사구·동명사구 허용 (`설치본 실행`, `usage API 스파이크`).

**코드·경로**  
백틱 유지. 문장 안 경로는 그대로 두고 주변만 존댓말.

## 예시 (Before → After)

| Before | After |
|--------|-------|
| 표시한다. | 표시합니다. |
| 더블클릭한다. | 더블클릭하세요. |
| 만들어 둔다. | 만들어 둡니다. |
| 쓰지 마세요. | (유지) 사용하지 마세요. |
| 읽는다. | 읽습니다. |
| 바뀌지 않는다. | 바뀌지 않습니다. |

## 적용 순서

1. 해체·공문체 문장을 찾는다.
2. 위 표에 맞게 어미만 바꾼다. 기술 내용·경로·명령은 건드리지 않는다.
3. 한 섹션 안에서 어미를 섞지 않는다 (안내=하세요, 설명=합니다).

## 참고

- 기준 문서: 루트 `README.md`
- 커밋 메시지 톤은 `korean-git-commit` (명사구 종결) — README 톤과 혼동하지 않는다.
